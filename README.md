# warrior-executive-aviation

Public site and crew portal for Warrior Executive Aviation.

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Production build

```bash
npm run build
npm run start
```

## Included pages

- Home
- About
- Fleet
- Services
- Safety
- Crew
- Careers
- Contact
- Crew Portal
